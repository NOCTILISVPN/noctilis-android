# NOCTILIS для Android

Собственное VPN-приложение NOCTILIS: ставишь, открываешь, одна кнопка «Подключить».
Регистрация, пробный период, оплата и кабинет — внутри приложения, без Telegram.

- План, решения и журнал проекта — [ЧТО-ЗДЕСЬ.md](ЧТО-ЗДЕСЬ.md).
- Ядро туннеля — [sing-box](https://github.com/SagerNet/sing-box) (подключается на этапе 1).
- Сборка — GitHub Actions, готовый APK лежит в [Releases](../../releases).

Лицензия: GPL-3.0 (как у sing-box).
